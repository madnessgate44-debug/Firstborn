# Forge Self-Diagnosis Verification

This document confirms that the Forge agent attaches a structured diagnosis to failed missions.

## Verification

Forge includes a `diagnosis` field in mission reports when a mission fails or is blocked. This diagnosis:
- Is generated by the `diagnoseMission` function in `src/agent/diagnosis.ts`
- Contains categorized root cause analysis
- Includes severity assessment
- Provides bounded, advisory recovery steps
- Is deterministic and pure (no network, model, or filesystem access)

The diagnosis is attached to the mission report and persisted in `.firstborn/evidence/` for post-mission review.

## Evidence

See:
- `src/agent/diagnosis.ts` - diagnosis implementation
- `tests/diagnosis.test.ts` - unit tests verifying classification logic
- `src/agent/forge-runner.ts` - shows diagnosis inclusion in report output
- `docs/forge-live-smoke-20261012.md` - example showing diagnosis in live smoke test

## Conclusion

Forge reliably attaches structured diagnosis to failed missions as required.
