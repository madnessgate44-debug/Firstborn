## Owner mandate

The owner has explicitly authorized the AI/engineering side to choose and execute the necessary approach. The desired outcome is that complete transcripts of every in-scope chat are synchronized to the correct GitHub Knowledge Bank without the owner needing to issue a command, export files, or remember a closeout step.

## Current root blocker

This ChatGPT execution environment has GitHub access but no verified API/event hook to read every ChatGPT thread, detect chat departure, or retrieve private conversation histories in the background. A cron job by itself cannot solve missing source access.

Official OpenAI documentation currently describes ChatGPT history export as a user-requested process through Settings or the Privacy Portal, with an export archive delivered later. It does not document a continuous per-message webhook or unattended API for exporting every personal ChatGPT conversation:
- https://help.openai.com/en/articles/7260999-exporting-your-chatgpt-history-and-data
- Android export instructions: https://help.openai.com/en/articles/8167885-how-to-export-your-data-from-the-chatgpt-android-app

This is evidence of the supported export path documented in those sources, not proof that no future/other integration could exist. The connected tools available in this execution have no verified ChatGPT conversation-history source.
